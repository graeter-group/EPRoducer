Installation
============

Requirements
------------

* Python >= 3.9
* numpy
* scipy
* matplotlib
* ase
* networkx
* pandas
* PlottingTool

Install
-------

Clone the repository and install in editable mode::

    cd /path/to/eprtools
    pip install -e .

This also installs the ``eprtools`` command-line tool.
To verify::

    eprtools -h
